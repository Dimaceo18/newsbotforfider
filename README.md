# 🏙 Minsk News Bot

Telegram-бот, который каждый час собирает свежие новости Минска из нескольких источников и публикует их в указанный канал.

## Источники новостей

| Источник | Тип |
|----------|-----|
| Onliner.by | RSS |
| БелТА | RSS |
| СБ «Беларусь Сегодня» | RSS |
| Зеркало | RSS |
| Google News — Минск | RSS |
| Google News — Беларусь | RSS |
| Telegram-канал Onliner | Парсинг t.me/s/ |
| Telegram-канал Мой Минск | Парсинг t.me/s/ |
| Telegram-канал СБ | Парсинг t.me/s/ |

## Быстрый старт

### 1. Создайте бота в Telegram

1. Откройте [@BotFather](https://t.me/BotFather)
2. Отправьте `/newbot` и следуйте инструкциям
3. Скопируйте **BOT_TOKEN**

### 2. Создайте и настройте канал

1. Создайте Telegram-канал (публичный или приватный)
2. Добавьте вашего бота как **администратора** с правом публикации
3. Скопируйте username канала (`@имя_канала`) или числовой ID

> Чтобы узнать числовой ID канала: добавьте бота [@userinfobot](https://t.me/userinfobot) в канал и отправьте любое сообщение.

### 3. Запуск через Docker (рекомендуется)

```bash
git clone <this-repo>
cd minsk-news-bot

# Настройте переменные окружения
cp .env.example .env
nano .env   # вставьте BOT_TOKEN и CHANNEL_ID

# Запуск
docker compose up -d

# Логи
docker compose logs -f
```

### 4. Запуск напрямую (Python 3.11+)

```bash
# Установка зависимостей
pip install -r requirements.txt

# Настройка переменных
export BOT_TOKEN="ваш_токен"
export CHANNEL_ID="@ваш_канал"

# Запуск
python bot.py
```

## Настройка

Все параметры находятся в начале `bot.py`:

| Параметр | Описание | По умолчанию |
|----------|----------|--------------|
| `MAX_AGE_HOURS` | Игнорировать новости старше N часов | `2` |
| `MAX_PER_RUN` | Максимум постов за один запуск | `10` |
| `RSS_FEEDS` | Список RSS-лент | см. код |
| `TELEGRAM_CHANNELS` | Telegram-каналы для парсинга | см. код |

### Добавить новый RSS-источник

```python
RSS_FEEDS.append({
    "name": "Моё СМИ",
    "url": "https://example.by/rss.xml",
    "keywords": ["минск"],  # [] — публиковать всё
})
```

### Добавить Telegram-канал

```python
TELEGRAM_CHANNELS.append({
    "name": "Название канала",
    "handle": "username_без_собаки",
})
```

> ⚠️ Парсинг работает только для **публичных** каналов через `t.me/s/`.

## Формат поста

```
📰 Заголовок новости

Краткое описание (если есть)...

🔗 Читать  •  🏙 Источник  •  🕐 14:30
```

## Дедупликация

Бот хранит хеши уже опубликованных новостей в файле `seen_news.json` (или `/app/data/seen_news.json` в Docker). Максимум 5 000 записей — старые автоматически вытесняются.

## Переменные окружения

| Переменная | Описание |
|------------|----------|
| `BOT_TOKEN` | Токен Telegram-бота |
| `CHANNEL_ID` | ID или @username канала |
| `LOG_LEVEL` | Уровень логов (`INFO`, `DEBUG`) |
